# LMK Web Studio | Developer Portfolio

A personal portfolio showcasing my projects and experiments.
Built with a focus on clean UI and creative styling, this portfolio blends functionality with a futuristic, scalable aesthetic. 

## ✨ Features ✨

- **Interactive Cursor Glow:** A glowing gradient follows the mouse, adding depth to the browsing experience. 
- **Dynamic Project Showcase:** Projects are rendered from a reusable projects array, making it easy to update and organize portfolio content.
- **Neon Glitch Contact Form:** A neon-inspired glitch effect adds a distinctive visual touch to the contact page.
- **Custom Contact Form:** A personalized contact form designed to provide visitors with a direct way to get in touch. 
- **Responsive Design:** An adaptable layout designed to provide a consistent experience across all devices. 

## 🛠️ Technologies Used 🛠️

- HTML
- CSS
- JavaScript / TypeScript
- Angular
- EmailJS
